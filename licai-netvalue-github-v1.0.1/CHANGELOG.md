# 更新说明

## 2026-11-04 · 前端版本 20261102r

### 新增
- **年视图月收益率**：每月在「年化」下方增加「月收益 x.xx%」
- **全年收益率**：年视图顶部「全年收益」旁新增「全年收益率」
- **已持有天数**：产品详情顶部展示从确认份额日起的持有天数
- **分批可赎回**：产品详情的「最近可赎回」按每一批分行展示（时间 + 份额）
- **买入 / 赎回选择器**：右下角加号改为两个 tab，输入产品代码自动带出产品名
- **交易记录增强**：按月分组，展示产品名、代码、购入/赎回净值，并标注每个日期含义（申请/净值日/完成/确认）
- **赎回完整字段**：提交申请时间、净值计算时间、赎回完成时间、赎回比例、赎回金额

### 优化
- **浏览器返回键**：在应用内回退（记录页/产品页 → 首页），返回首页会恢复原滚动位置，不再直接退出网页
- **赎回完成时间**：按产品 T+N 自动计算（T+1 / T+2，跳过周末），修改申请时间会自动重算
- **月收益率口径**：分母改为「整月已过天数」，月中买入会被时间加权摊薄，与说明口径一致
- **总投入**：改为累计买入实付，卖出后不再出现负数
- **性能**：本地缓存 + 渐进加载（先出产品/交易，净值后到）；净值接口去掉冗余字段，体积约 -27%

### 修复
- 年视图因 `monthRate` 未传入导致「页面渲染出错」
- 新买入产品在首个可见净值日之前被误判为「未更新」
- 交易记录产品名不显示（字段 `display_name` 兼容）
- 年视图过去/未来月份底色、选中月高亮
- 赎回中徽章位置与胶囊配色统一（买入紫、赎回红、赎回中橙、已全部更新蓝）

### 从旧版升级（已有数据库）
新版交易表新增 3 个字段，需在 D1 Console 执行一次：

```sql
ALTER TABLE transactions ADD COLUMN apply_date TEXT;
ALTER TABLE transactions ADD COLUMN settle_date TEXT;
ALTER TABLE transactions ADD COLUMN redeem_ratio TEXT;
```

执行后重新部署即可，**无需清空数据**。

### 全新部署
直接用 `schema.sql` 建表即可，已包含以上字段，无需额外迁移。
